# int-shipping 실무자 가이드 (매일 하는 일만)

해외주문 발송 처리 툴에서 **실제로 눌러야 하는 버튼만** 순서대로 정리했습니다.
버튼 하나하나의 자세한 동작은 [전체 사용 가이드](./사용가이드.md)를 보세요.

---

## 시작하기 전에 (처음 한 번 / 가끔)

- [ ] 크롬에서 int-shipping에 `@geon.works` 계정으로 로그인
- [ ] 같은 크롬에서 **DHL Express Commerce**에 로그인
- [ ] 크롬 확장 프로그램 **GEONWORKS DHL 자동화 1.3 이상** 설치 (모르면 담당자에게 요청)

화면에 "확장 프로그램이 예전 버전입니다"가 뜨면 담당자에게 알려주세요.

---

## ① 해외(DHL) 주문 보내기 — 매일

### 1. 라벨 뽑기

1. **DHL 발송건** 탭을 엽니다.
2. 오늘 보낼 주문을 **체크**합니다.
3. **라벨 자동 출력**을 누릅니다.
4. DHL 창이 열리고 자동으로 움직입니다. **DHL 창은 건드리지 말고 기다립니다.**
5. **"DHL 신고 가액 확인"** 창이 뜨면:
   - 빨간 줄이 **없으면** → 오른쪽 아래 **라벨 출력**
   - 빨간 줄이 **있으면** → 처리 칸이 **할인가**로 되어 있는지 확인 → **DHL 가액 N개 수정 + 라벨 출력**

   이상해 보이면 **취소**를 누르세요. 아무것도 바뀌지 않습니다.
6. 다시 기다립니다. 라벨 PDF와 DHL 리포트는 **다운로드 폴더**에 자동으로 저장됩니다.
7. 화면이 **처리완료 조회** 탭으로 바뀌고 **원산지 확인** 창이 뜹니다.

### 2. 포장대장 / 수출신고 파일 만들기

1. **원산지 확인** 창에서 **빨간 테두리 칸**에 원산지 2글자를 적습니다. (예: 한국 `KR`, 중국 `CN`, 독일 `DE`)
2. **확인 후 엑셀 생성**을 누릅니다.
   - 창 위에 **"⚠ DHL 신고 금액이 Shopify 결제 금액과 다른 주문"**이 떠도 파일은 만들어집니다. (수출신고는 Shopify 금액 기준) 목록의 주문번호만 담당자에게 알려주세요.
3. 파일 두 개가 받아집니다.
   - `N월 N일 출고분.xlsx` → **포장할 때 보는 대장**
   - `GMI_DEC 수출신고요청_…xlsx` → **수출신고 담당에게 전달**

### 3. 재고 빼기 (포장 끝난 뒤)

1. **처리완료 조회** 탭에서 오늘 보낸 주문이 체크돼 있는지 확인합니다. (라벨 자동 출력 후엔 **이번에 출력한 주문만** 자동 체크)
2. **선택 주문 재고차감**을 누릅니다.
3. 확인 창에서 **빨간 칸**이 있으면 담당자에게 확인 → **확인, 재고차감 진행**
4. 상태 칸에 **✓ 재고차감 완료**가 뜨면 끝

이미 재고차감된 주문은 체크돼 있어도 **자동으로 빠집니다.** (확인 창에 "이미 재고차감 완료 — 제외")

상태 칸에 **⚠ 차감 안 됨 — SKU 매칭 실패**가 뜨면 그 주문은 재고가 **하나도 빠지지 않은** 것입니다. 담당자에게 알려주세요. SKU를 고친 뒤 다시 **선택 주문 재고차감**을 누르면 됩니다.

---

## ② 국내 주문 보내기

1. **국내 배송건** 탭을 엽니다.
2. 주문마다 **운송장번호**를 적고 **발송처리**를 누릅니다.
3. "발송처리 + 재고차감 완료"가 뜨면 끝입니다. (고객에게 발송 메일이 자동으로 나갑니다)

"SKU 매칭 실패"가 뜨면 → 그 품목만 재고가 안 빠진 것이니 담당자에게 알려주세요.

---

## ③ 가끔 하는 일

### 라벨 없이 DHL 가격만 고치고 싶을 때

1. **DHL 발송건** 탭에서 주문을 체크하거나, 입력칸에 주문번호(예: `28783`)를 적습니다.
2. **가액만 확인·수정**을 누릅니다.
3. 창에서 빨간 줄 확인 → **DHL 가액 N개 수정 (라벨 출력 안 함)**
4. "완료"가 뜨면 끝입니다. **라벨은 출력되지 않습니다.**

### 포장대장 / 수출신고 파일을 다시 만들어야 할 때

1. DHL 사이트 **Reports**에서 그날 리포트 xlsx를 다운로드합니다.
2. **처리완료 조회** 탭 → **DHL 리포트 업로드**에 그 파일을 넣습니다. **리포트에 있는 주문이 전부 자동 체크**됩니다. (빼고 싶은 주문만 체크 해제)
3. **포장대장/수출신고 파일 생성** → 원산지 확인 → **확인 후 엑셀 생성**

리포트를 넣기 전에는 버튼이 **흐리게 눌리지 않습니다.** 정상입니다.

### 주소가 틀렸을 때

주문의 **주소 수정**을 눌러 고치고 저장합니다. **Shopify 주문 주소가 바로 바뀝니다.**

---

## 하면 안 되는 것

- 자동화 중인 **DHL 창을 클릭하거나 닫기** → 멈춥니다. 닫았다면 처음부터 다시 누르세요.
- 가격 확인 창에서 뭔지 모르고 **"전체 정가로"** 누르기 → DHL 가격이 할인 전 가격으로 바뀝니다

---

## 막혔을 때

| 화면에 뜬 문구 | 할 일 |
|---|---|
| 확장 프로그램 … 예전 버전 / 응답이 없습니다 | 담당자에게 확장 프로그램 업데이트 요청 |
| 체크박스로 주문을 먼저 선택해주세요 | 주문을 체크하고 다시 |
| 이미 진행 중인 자동화 작업이 있습니다 | 열려 있는 DHL 창이 끝날 때까지 기다리거나, 그 창을 닫고 다시 |
| DHL 주문 목록에서 찾지 못했습니다 | 이미 라벨을 뽑은 주문일 수 있음 → 담당자 확인 |
| 가액이 저장되지 않았습니다 | DHL에서 그 주문 가격을 직접 확인 → 담당자에게 알림 |
| 비어있는 원산지코드가 있습니다 | 빨간 칸에 원산지 적기 |

그 밖의 문구는 **화면을 캡처해서** 담당자에게 보내주세요.
