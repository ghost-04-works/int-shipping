# int-shipping 실무자 가이드 (매일 하는 일만)

해외주문 발송 처리 툴에서 **실제로 눌러야 하는 버튼만** 순서대로 정리했습니다.
버튼 하나하나의 자세한 동작은 [전체 사용 가이드](./사용가이드.md)를 보세요.

---

## 시작하기 전에 (처음 한 번 / 가끔)

- [ ] 크롬에서 int-shipping에 `@geon.works` 계정으로 로그인
- [ ] 같은 크롬에서 **DHL Express Commerce**에 로그인
- [ ] 크롬 확장 프로그램 **GEONWORKS DHL 자동화 1.5 이상** 설치 (모르면 담당자에게 요청)

화면에 "확장 프로그램이 예전 버전입니다"가 뜨면 담당자에게 알려주세요.

> ⚠ **작업 전에 DEC(DHL Express Commerce) 계정부터 확인하세요.**
> - **일반 주문(Shopify)** → **일반 계정** (DEC 오른쪽 위에 `sw0780@naver.com`)
> - **벤더 주문(B2B)** → **B2B 계정** (`GMI(B2B)_598898968`)
>
> 라벨 자동 출력·가액 확인은 일반 계정이 아니면 **자동으로 멈춥니다**("DEC 계정이 …입니다"). 계정을 바꾸고 다시 누르세요.
>
> 계정을 잘못 둔 채로 작업하면 주문이 **다른 계정에 들어가 버립니다.** (예: B2B 계정 상태에서 라벨 자동 출력 → 일반 주문이 B2B 계정에 입력됨)
> 벤더 작업을 마치면 **일반 계정으로 되돌려** 두세요.

---

## ① 해외(DHL) 주문 보내기 — 매일

### 1. 라벨 뽑기

0. **DEC가 일반 계정인지 확인합니다.** B2B 계정이면 일반 계정으로 바꾼 뒤 시작하세요.
1. **DHL 발송건** 탭을 엽니다.
2. 오늘 보낼 주문을 **체크**합니다.
3. **라벨 자동 출력**을 누릅니다.
4. DHL 창이 열리고 자동으로 움직입니다. **DHL 창은 건드리지 말고 기다립니다.**
5. **"DHL 신고 가액 확인"** 창이 뜨면:
   - 빨간 줄이 **없으면** → 오른쪽 아래 **라벨 출력**
   - 빨간 줄이 **있으면** → 처리 칸이 **할인가**로 되어 있는지 확인 → **DHL 가액 N개 수정 + 라벨 출력**

   - **수량**에 빨간 "2 / DHL 3 of 3"이 있으면 → 기본값 **→ 2 of 2** 그대로 (DHL 수량을 Shopify에 맞춤)
   - **DHL에 없음** 품목 → 기본값 **DHL에 추가**. 아래 **kg 칸이 비어 있으면 무게를 적고, 원산지가 "원산지 선택"이면 골라야** 진행됩니다. 추가하지 않을 거면 **추가 안 함**
   - **Shopify에 없는 DHL 품목** → 기본값 **DHL에서 삭제** (취소된 품목이 DHL에 남은 것). 남겨야 하면 **유지**

   이상해 보이면 **취소**를 누르세요. 아무것도 바뀌지 않습니다.
6. 다시 기다립니다. 라벨 PDF와 DHL 리포트는 **다운로드 폴더**에 자동으로 저장됩니다.
7. 화면이 **처리완료 조회** 탭으로 바뀌고 **원산지 확인** 창이 뜹니다.

### 2. 포장대장 / 수출신고 파일 만들기

1. **원산지 확인** 창에서 **빨간 테두리 칸**에 원산지 2글자를 적습니다. (예: 한국 `KR`, 중국 `CN`, 독일 `DE`)
2. **확인 후 엑셀 생성**을 누릅니다.
   - 창 위에 **"⚠ DHL 신고 금액이 Shopify 결제 금액과 다른 주문"**이 떠도 파일은 만들어집니다. (수출신고는 Shopify 금액 기준) 목록의 주문번호만 담당자에게 알려주세요.
3. 파일 두 개가 받아집니다.
   - `N월 N일 출고분.xlsx` → **포장할 때 보는 대장**
   - `GMI_DEC 수출신고요청_…xlsx` → **수출신고 메일 첨부용**

### 3. 재고 빼기 (포장 끝난 뒤)

1. **처리완료 조회** 탭에서 오늘 보낸 주문이 체크돼 있는지 확인합니다. (라벨 자동 출력 후엔 **이번에 출력한 주문만** 자동 체크)
2. **선택 주문 재고차감**을 누릅니다.
3. 확인 창에서 **빨간 칸**이 있으면 담당자에게 확인 → **확인, 재고차감 진행**
4. 상태 칸에 **✓ 재고차감 완료**가 뜨면 끝

이미 재고차감된 주문은 체크돼 있어도 **자동으로 빠집니다.** (확인 창에 "이미 재고차감 완료 — 제외")

상태 칸에 **⚠ 차감 안 됨 — SKU 매칭 실패**가 뜨면 그 주문은 재고가 **하나도 빠지지 않은** 것입니다. 담당자에게 알려주세요. SKU를 고친 뒤 다시 **선택 주문 재고차감**을 누르면 됩니다.

---

## ② 국내 주문 보내기

1. **국내 배송건** 탭을 엽니다.
2. 주문마다 **운송장번호**를 적고 **발송처리**를 누릅니다.
3. "발송처리 + 재고차감 완료"가 뜨면 끝입니다. (고객에게 발송 메일이 자동으로 나갑니다)

"SKU 매칭 실패"가 뜨면 → 그 품목만 재고가 안 빠진 것이니 담당자에게 알려주세요.

---

## ②-1 벤더(B2B) 주문 보내기

벤더 주문 사이트의 **DHL 발송 주문**이 **벤더 발송건** 탭에 나옵니다. (기본: 입금확인 주문만)

### 1. DHL CSV 만들기 (운송장 만들기 전)

1. **벤더 발송건** 탭에서 보낼 주문을 **체크**합니다.
2. **DHL CSV 만들기**를 누릅니다.
3. 창에서 **품목명**(Keyboard Switch 등)과 **원산지**를 확인합니다.
   - 원산지 칸이 빨간 테두리 → 원산지 2글자를 적습니다.
   - 카테고리 칸에 빨간 **없음** → 품목명을 직접 골라 주세요.
4. **CSV 만들기** → `DHL_CSV_B260929001_0930.csv` 같은 파일이 받아집니다.
5. DEC에서 **B2B 계정으로 바꾼 것을 확인한 뒤**(또는 필요하면 일반 계정) 이 CSV를 올려 운송장을 만듭니다.
6. 운송장을 다 만들면 **DEC를 일반 계정으로 되돌립니다.** 그대로 두면 다음 일반 주문 작업이 B2B 계정에 들어갑니다.

### 2. 수출신고 파일 만들기 (운송장 나온 뒤)

1. 같은 주문을 체크하고 **수출신고 파일 만들기**를 누릅니다.
2. 주문마다 **AWB(운송장번호)**, **CT(박스 수)**, **총중량**을 입력합니다.
3. **수출신고 파일 만들기** → `GMI_DEC 수출신고요청_B2B_N건_MMDD.xlsx`가 받아집니다.

창 아래 **신고 합계**가 인보이스 Grand Total과 다르면 빨간 글씨로 이유가 나옵니다(크레딧, 할인 반올림). 확인 후 진행하세요.

## ③ 가끔 하는 일

### 라벨 없이 DHL 가격만 고치고 싶을 때

1. **DHL 발송건** 탭에서 주문을 체크하거나, 입력칸에 주문번호(예: `28783`)를 적습니다.
2. **가액만 확인·수정**을 누릅니다.
3. 창에서 빨간 줄 확인 → **DHL … 수정 (라벨 출력 안 함)** (품목 추가·삭제·수량도 같은 창에서 — 위 ①-1의 5번 참고)
4. "완료"가 뜨면 끝입니다. **라벨은 출력되지 않습니다.**

### 포장대장 / 수출신고 파일을 다시 만들어야 할 때

1. DHL 사이트 **Reports**에서 그날 리포트 xlsx를 다운로드합니다.
2. **처리완료 조회** 탭 → **DHL 리포트 업로드**에 그 파일을 넣습니다. **리포트에 있는 주문이 전부 자동 체크**됩니다. (빼고 싶은 주문만 체크 해제)
3. **포장대장/수출신고 파일 생성** → 원산지 확인 → **확인 후 엑셀 생성**

리포트를 넣기 전에는 버튼이 **흐리게 눌리지 않습니다.** 정상입니다.

### 재고를 직접 빼야 할 때 (수동 재고차감)

이럴 때 씁니다.
- 재고차감 결과에 **⚠ SKU 매칭 실패** / **⚠ 차감 안 됨**이 떴을 때 (그 품목은 재고가 안 빠진 것)
- 주문과 상관없이 샘플 발송·재고 보정 등으로 재고를 빼야 할 때

**특정 주문의 재고를 뺄 때**
1. **처리완료 조회** 탭에서 그 주문의 상태 칸에 있는 **수동차감** 버튼을 누릅니다. (재고차감이 안 된 주문에만 보입니다)
2. 창 위에 "연결된 주문: #…"이 보이는지 확인합니다.
3. **품목 칸의 검색**을 눌러 셀메이트 상품을 찾아 고르고, **수량**을 적습니다. 품목이 여러 개면 **+ 품목 추가**.
4. **차감 창고**가 맞는지 확인합니다. (기본: 해외창고(3))
5. **재고차감 실행** → 그 주문 상태가 **✓ 재고차감 완료**로 바뀝니다.

**주문과 상관없이 뺄 때**
1. **처리완료 조회** 탭 위쪽의 **수동 재고차감** 버튼을 누릅니다.
2. 위와 같이 품목·수량·창고를 고르고, **셀메이트 작업 메모**에 이유를 적습니다. (예: 샘플 발송)
3. **재고차감 실행**

주의
- 주문에 연결해서 뺀 주문은 **다시 뺄 수 없습니다** (중복 방지). 주문과 상관없이 빼는 경우는 **중복 방지가 없으니** 두 번 누르지 마세요.
- 차감 창고를 모르면 담당자에게 확인하세요. 해외벤더(6)는 벤더용 재고입니다.

### 주소가 틀렸을 때

주문의 **주소 수정**을 눌러 고치고 저장합니다. **Shopify 주문 주소가 바로 바뀝니다.**

---

## 하면 안 되는 것

- 자동화 중인 **DHL 창을 클릭하거나 닫기** → 멈춥니다. 닫았다면 처음부터 다시 누르세요.
- 가격 확인 창에서 뭔지 모르고 **"전체 정가로"** 누르기 → DHL 가격이 할인 전 가격으로 바뀝니다
- **DEC 계정 확인 없이 작업 시작하기** → 일반 주문이 B2B 계정에(또는 반대로) 들어갑니다. 일반 주문은 일반 계정, 벤더 주문은 B2B 계정

## 막혔을 때

| 화면에 뜬 문구 | 할 일 |
|---|---|
| 확장 프로그램 … 예전 버전 / 응답이 없습니다 | 담당자에게 확장 프로그램 업데이트 요청 |
| @geon.works 계정 로그인이 필요합니다 / 로그인이 만료되었습니다 | 새로고침(F5) 후 다시 로그인 |
| 체크박스로 주문을 먼저 선택해주세요 | 주문을 체크하고 다시 |
| 이미 진행 중인 자동화 작업이 있습니다 | 열려 있는 DHL 창이 끝날 때까지 기다리거나, 그 창을 닫고 다시 |
| DHL 주문 목록에서 찾지 못했습니다 | 이미 라벨을 뽑은 주문일 수 있음 → 담당자 확인 |
| 가액이 저장되지 않았습니다 / 품목 수정이 저장되지 않았습니다 | DHL에서 그 주문 품목·가격을 직접 확인 → 담당자에게 알림 |
| DEC 계정이 GMI(B2B)_…입니다 | DEC를 일반 계정(`sw0780@naver.com`)으로 바꾸고 다시 |
| 단가·무게(kg)·원산지가 비었거나… | 창의 빨간 칸(추가할 품목 무게·원산지)을 채우거나 "추가 안 함" |
| Item details 창의 "…" 칸에 값이 들어가지 않았습니다 | 저장 없이 멈춘 것 → DHL에서 그 주문 직접 확인 → 담당자에게 알림 |
| 벤더 주문 조회 실패 | 잠시 뒤 새로고침(F5). 계속되면 담당자에게 알림 |
| ⚠ SKU 매칭 실패 / ⚠ 차감 안 됨 | 그 품목(주문)은 재고가 안 빠짐 → **수동 재고차감**으로 빼기 |
| DHL CSV에 쓸 수 없는 문자(한글 등)가 있습니다 | 벤더 주문 배송지에 한글 등이 있음 → 담당자에게 알림 |
| 비어있는 원산지코드가 있습니다 | 빨간 칸에 원산지 적기 |

그 밖의 문구는 **화면을 캡처해서** 담당자에게 보내주세요.
