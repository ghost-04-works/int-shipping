# int-shipping 사용 가이드 (전체 기능)

해외주문 발송 처리 툴(https://ghost-04-works.github.io/int-shipping/)의 탭과 버튼이 **무엇을 하고, 무엇을 바꾸는지** 정리한 문서입니다.
매일 하는 작업 순서만 필요하면 [실무자 가이드](./실무자_가이드.md)를 보세요.

---

## 1. 준비

| 항목 | 내용 |
|---|---|
| 로그인 | `@geon.works` 구글 계정으로 로그인. 로그인은 브라우저에 유지되고 자동 연장됩니다. 주문 조회·재고차감 등 서버 기능도 로그인한 `@geon.works` 계정만 쓸 수 있습니다. |
| 크롬 확장 프로그램 | **GEONWORKS DHL 자동화** 1.3 이상이 설치돼 있어야 "라벨 자동 출력", "가액만 확인·수정"이 동작합니다. 버전이 낮거나 없으면 int-shipping이 요청을 보내지 않고 안내 문구를 띄웁니다. (설치: 13장) |
| DHL Express Commerce | 같은 크롬에서 `app2.dhlexpresscommerce.com`에 로그인된 상태여야 합니다. |
| **DEC 계정 (필수 확인)** | **일반 주문(Shopify)은 일반 계정, 벤더 주문은 B2B 계정**에서 작업합니다. 자동화와 CSV 업로드는 **지금 로그인된 계정**에 그대로 들어가서, B2B 계정 상태로 일반 건을 작업하면 일반 주문이 B2B 계정에 입력됩니다. 작업 전에 계정을 확인하고, 벤더 작업이 끝나면 일반 계정으로 되돌려 두세요. |

## 2. 주문이 탭에 나뉘는 기준

Shopify의 **미발송 주문**을 불러와 아래 기준으로 나눕니다.

| 탭 | 들어가는 주문 |
|---|---|
| **DHL 발송건** | 배송방법에 "DHL"이 들어간 주문. 배송방법이 애매하면 배송지가 한국이 아닌 주문 |
| **국내 배송건** | 배송방법에 "국내"가 들어간 주문, 또는 배송지가 한국(KR)인 주문 |
| **Group Buy (제외됨)** | 품목명이 `[Group Buy]` 또는 `[Pre-Order]`로 시작하는 품목이 하나라도 있는 주문 (기본 발송 대상에서 제외) |
| **처리완료 조회** | Shopify에서 **발송완료**된 주문 (라벨 출력 후 DHL이 자동으로 발송완료 처리) |
| **벤더 발송건** | Shopify가 아니라 **벤더 주문 사이트**의 주문 중 배송 방식이 DHL인 주문 (7-B) |

배송방법 배지에 "(추정)"이 붙어 있으면 배송방법 문구가 아니라 배송지 국가로 분류된 주문입니다.

## 3. 모든 탭 공통

| 기능 | 동작 | 바뀌는 것 |
|---|---|---|
| **↻ 새로고침** | Shopify 미발송 주문을 다시 불러옵니다. | 없음 |
| **주소 수정** (주소 칸, 처리완료 탭 제외) | 배송 주소 수정 창 → 저장하면 **Shopify 주문의 배송지가 바뀝니다.** | Shopify 배송지 |
| **관세확인** 체크박스 | 작업 중 표시용입니다. 저장되지 않고 새로고침하면 사라집니다. | 없음 |
| **메모** 표시 | Shopify 주문 메모가 있으면 주문번호 아래에 보입니다. 마우스를 올리면 전체 내용이 보입니다. | 없음 |
| 체크박스 / 전체 선택 | DHL 발송건, Group Buy, 처리완료 탭에서 작업할 주문을 고릅니다. | 없음 |

## 4. DHL 발송건 탭

### 4-1. 라벨 자동 출력

> ⚠ 시작 전에 DEC가 **일반 계정**인지 확인하세요. B2B 계정 상태로 진행하면 일반 주문이 B2B 계정에 입력됩니다.

체크한 주문을 대상으로 아래 과정을 **자동으로** 진행합니다. DHL 탭이 새로 열리며, 진행 상황은 버튼 옆 문구로 보입니다.

1. **DHL 단가 읽기**: 주문마다 DHL 주문 상세 화면을 열어 품목·SKU·수량·Unit Price를 읽습니다. 아무것도 바꾸지 않습니다.
2. **DHL 신고 가액 확인 창**: Shopify 결제 단가와 DHL 단가를 비교해 보여줍니다. (4-3 참고)
3. **확인**을 누르면
   - 최종 단가가 DHL과 다른 품목만 DHL에서 수정합니다. 수정 방식은 품목 연필 → Item details → UNIT PRICE → UPDATE ORDER → SAVE입니다.
   - DHL 주문 목록에서 대상 주문을 체크하고 **Print shipping labels**로 라벨 PDF를 받습니다.
   - DHL 리포트 화면에서 오늘 날짜 리포트를 생성해 xlsx를 받습니다.
4. int-shipping이 **처리완료 조회** 탭으로 넘어가 리포트를 자동 업로드합니다. DHL 리포트에는 **오늘 출력한 라벨이 전부** 들어 있지만, **이번에 라벨을 출력한 주문만** 자동으로 체크됩니다. 상태 문구에 "이번 출력분 N건만 선택 (그 전에 출력한 M건 제외)"로 표시됩니다.
5. **포장대장/수출신고 파일 생성**을 자동으로 누르고 **원산지 확인 창**에서 멈춥니다. 여기부터는 사람이 확인합니다.

라벨이 출력되면 **DHL이 Shopify 주문을 발송완료로 처리**합니다. int-shipping이 하는 게 아니라 DHL과 Shopify의 연동 기능입니다. 그래서 DHL 발송건 탭 목록에서 빠집니다.

비교 창에서 **취소**를 누르면 DHL은 아무것도 바뀌지 않고 라벨도 출력되지 않습니다.

### 4-2. 가액만 확인·수정

라벨 출력 **없이** DHL 가액만 확인하고 고칩니다.

| 입력칸 | 대상 |
|---|---|
| 비워둠 | 체크한 주문들 (일괄) |
| 주문번호 입력 (예: `28783`) | 그 주문 하나. Shopify에서 취소·보관된 주문도 DHL 주문의 Reference #로 찾아옵니다. |

진행은 4-1의 1~2단계와 같고, 확인 버튼이 **"DHL 가액 N개 수정 (라벨 출력 안 함)"**으로 바뀝니다. 끝나면 DHL 탭이 닫히고 "완료: DHL 가액 수정 N건 (라벨 출력 안 함)"이 뜹니다.
Shopify 발송처리, 라벨 출력, 재고차감은 **절대 하지 않습니다.**

### 4-3. DHL 신고 가액 확인 창 보는 법

| 열 | 의미 |
|---|---|
| Shopify | ~~정가~~ 할인가 (할인이 없으면 가격 하나만 표시). "(정가)"로 표시되면 할인가 정보를 받지 못한 것입니다. |
| DHL | DHL(DEC)에 현재 들어가 있는 Unit Price. **빨간색 = Shopify 할인가와 다름** |
| 처리 | **할인가** / **정가** / **DHL 유지** / **직접 입력** |
| 최종 단가 | DHL에 넣을 값 (수출신고 파일 단가와는 무관 — 수출신고는 항상 Shopify 결제 단가) |

- 불일치 품목의 기본값은 **할인가**, 일치 품목의 기본값은 **DHL 유지(일치)**입니다.
- 일괄 버튼: **전체 할인가로 / 전체 정가로 / 전체 DHL 유지**
- **불일치만 보기**: 체크하면 다른 품목만 보입니다.
- 요약 줄에 "DHL에 없는 품목", "Shopify에 없는 DHL 품목", "DHL에서 못 찾은 주문"이 뜨면 주문 내용이 서로 다른 것이니 DHL에서 직접 확인하세요.
- 확인 버튼 문구에 **DHL에서 실제로 바뀔 품목 수**가 나옵니다. 0개면 "닫기"(가액만) 또는 "라벨 출력"(라벨 자동 출력)입니다.
- 수출신고 파일에는 여기서 고른 값과 상관없이 **Shopify 실제 결제 단가(할인가, 할인 없으면 정가)**가 들어갑니다. 그래서 어느 PC에서 파일을 만들어도 같습니다. DHL을 정가·직접 입력으로 맞추면 파일 생성 때 "DHL 신고 금액이 다른 주문"으로 안내됩니다.

## 5. 국내 배송건 탭

주문마다 **운송장번호**를 입력하고 **발송처리**를 누르면 한 번에 두 가지가 처리됩니다.

1. **Shopify 발송처리**: 택배사 "우체국택배"와 운송장번호가 등록되고, **고객에게 발송 알림 메일이 나갑니다.**
2. **셀메이트 재고차감**: 해외창고(3)에서 차감합니다. 메모는 `Shopify #주문번호`입니다.

"SKU 매칭 실패"가 뜨면 발송처리는 됐지만 그 품목의 재고는 빠지지 않은 것이니 **수동 재고차감**으로 처리하세요.

## 6. Group Buy (제외됨) 탭

기본 발송 대상에서 빠진 주문입니다. 이 중 일부를 DHL로 보내야 할 때는 이 탭에서 체크하고 **라벨 자동 출력** 또는 **가액만 확인·수정**을 쓸 수 있습니다. 동작은 DHL 발송건 탭과 같습니다.

## 7. 처리완료 조회 탭

### 7-1. 목록과 검색

- Shopify **발송완료** 주문을 최근 순으로 250건씩 불러옵니다. 더 필요하면 맨 아래 **더 보기**를 누르세요.
- **주문번호로 검색**: 입력하면 바로 검색됩니다. **전체 목록 보기**를 누르면 검색이 해제됩니다.
- 상태 칸: Shopify 발송 상태와 **재고차감 완료(날짜)** 또는 **재고차감 안 됨 + [수동차감]**이 표시됩니다.

### 7-2. DHL 리포트 업로드

DHL 리포트 xlsx(PackageSentReport)를 넣으면 **"N건 매칭 데이터 로드됨 — N건 자동 선택됨"**이 뜨고, 리포트에 있는 주문이 자동으로 체크됩니다. 라벨 자동 출력을 쓰면 자동으로 들어갑니다.

- 불러온 목록에 없는 리포트 주문(오래된 주문 등)은 **주문번호로 자동 조회해서 목록에 추가**합니다. 그래도 못 찾으면 "⚠ Shopify에서 못 찾은 주문"으로 표시됩니다.
- 직접 올린 리포트에서는 **그 리포트의 주문을 전부 체크합니다**(파일을 이미 만든 주문도 포함). 리포트를 올리기 전에 체크해 둔 주문은 해제됩니다. 전에 파일을 만든 주문은 상태 칸에 "📄 파일 생성 (날짜 시간)"으로 표시됩니다(그 브라우저에 30일 보관).
- 파일을 만들 때 **리포트에 없는 주문이 체크돼 있으면 제외**하고 알려줍니다.
리포트에서 읽는 값은 받는 사람, 주문번호, 무게, 송장번호, 배송비, 박스 수입니다.

### 7-3. 선택 주문 재고차감

체크한 주문의 품목을 **셀메이트 해외창고(3)에서 차감**합니다.

1. **재고차감 확인 창**이 먼저 뜹니다. 빨간 테두리는 셀메이트에 없는 SKU입니다. 검색으로 고치거나, 비우면 그 품목은 차감에서 빠집니다.
2. **확인, 재고차감 진행**을 누르면 차감되고 "성공/스킵/실패" 건수가 표시됩니다.

Shopify 발송처리는 하지 않습니다. DHL이 라벨 출력 때 이미 했기 때문입니다.
**이미 재고차감 완료된 주문은 체크돼 있어도 자동으로 제외**됩니다. 확인 창에 "이미 재고차감 완료 — 제외"로 표시됩니다.

### 7-4. 포장대장/수출신고 파일 생성

**DHL 리포트를 올려야 버튼이 눌립니다.**

1. 체크한 주문의 SKU로 셀메이트에서 **원산지 코드**를 조회합니다.
2. **원산지 확인 창**: 빨간 테두리는 원산지가 없는 품목입니다. 직접 2자리 코드(예: `KR`, `CN`, `DE`)를 입력하세요. 빈칸이 있으면 진행되지 않습니다.
3. **확인 후 엑셀 생성**을 누르면 파일 두 개를 내려받습니다. (8장)

Shopify, DHL, 셀메이트 어느 것도 바꾸지 않으므로 몇 번 다시 만들어도 괜찮습니다.

### 7-5. 수동 재고차감

주문과 상관없이, 또는 특정 주문(상태 칸의 **수동차감**)에 대해 품목을 직접 골라 차감합니다.

- 차감 창고: **해외창고(3)** 또는 **해외벤더(6)**
- 품목은 **검색**으로 셀메이트 SKU를 골라야 합니다. 수량은 1 이상입니다.
- 주문에 연결해서 차감하면 그 주문은 "재고차감 완료"로 표시되고, 같은 주문으로 다시 차감할 수 없습니다.

## 7-B. 벤더 발송건 탭

> ⚠ 벤더 CSV는 DEC **B2B 계정**에 올립니다(필요한 경우만 일반 계정). 올리기 전에 계정을 확인하고, 끝나면 **일반 계정으로 되돌려** 두세요. 그대로 두면 다음 일반 주문 작업(라벨 자동 출력 등)이 B2B 계정에 들어갑니다.

벤더 주문 사이트(geon_vsale)의 주문 중 **배송 방식이 DHL이고, 취소·외부 발송이 아닌 최근 90일 주문**을 보여줍니다. 위의 선택 상자로 **입금확인 주문만**(기본)과 **전체**를 바꿉니다. 벤더 사이트에는 아무것도 쓰지 않습니다(읽기 전용 `vendor-orders` 함수). 재고차감도 하지 않습니다(벤더 사이트가 주문 때 처리).

### DHL CSV 만들기

DEC B2B 업로드 템플릿 양식(58열, CP949)으로 **품목마다 한 줄**을 만듭니다.

| 칸 | 값 |
|---|---|
| Order Number | `B` + 인보이스 번호 숫자 (GMI260929001 → `B260929001`) |
| To Name | 배송지 회사명 (없으면 이름) |
| Destination Street | 주소1, 주소2, "도시, 우편번호" (인보이스 표기 그대로) |
| City / Postcode / State / Country | 도시(대문자) / 우편번호 / 주 / 국가코드 |
| Email / Phone | 배송지 이메일 / 전화번호 |
| Item Name | 정해진 품목명 (아래) |
| Item Price | 신고 단가 — 품목 할인과 주문 전체 할인을 모두 반영한 단가 |
| Qty / Country of Manufacturer | 수량 / 원산지 |

나머지 칸은 비웁니다. 배송지에 한글 등 영문이 아닌 글자가 있으면 만들지 않고 알려줍니다(악센트는 자동으로 뗌: é → e).

**품목명 규칙** (확인 창에서 품목마다 바꿀 수 있음)

| 품목명 | 대상 |
|---|---|
| Keyboard Switch Spring | 상품명에 `Spring 14mm`처럼 mm 길이가 붙은 스프링 (Leaf Spring 등은 제외) |
| Keyboard Switch | 카테고리 switch |
| Keyboard PCB | 카테고리 pcb |
| Keyboard Plate | 카테고리 plate |
| Keyboard DIY Kit | 카테고리 housing |
| Keyboard Parts | 그 밖의 모든 상품 |

카테고리는 벤더 사이트 카탈로그의 상품 카테고리를 씁니다. 확인 창의 카테고리 칸에 빨간 **"없음"**이 보이면 그 상품은 카테고리가 비어 있는 것이니 품목명을 직접 고르세요.

### 수출신고 파일 만들기

주문마다 **AWB, CT, 총중량**을 입력하면 Shopify용과 같은 GMI 양식으로 만듭니다. 다른 점:

- 모델명(규격): 정해진 품목명
- 거래구분: **11** (Shopify는 15)
- 구매자: 배송지 회사명(없으면 이름), 대문자로 바꾸지 않음
- 마지막 줄 SHIPPING FEE: 인보이스 배송비(배송비 할인 반영)
- 총신고금액: 품목 금액 합 + 배송비. 크레딧은 빼지 않습니다. 인보이스 Grand Total과 다르면 확인 창에 이유가 표시됩니다.

### 포장대장

오더, 송장번호, 확인(빈칸), 품목명, 수량, 확인(빈칸). 수량이 2개 이상인 칸은 노란 배경에 빨간 글씨로 표시됩니다.

### 수출신고 파일 (GMI)

| 칸 | 값 |
|---|---|
| AWB NO, CT, 총중량 | DHL 리포트 (송장번호, 박스 수, 무게) |
| 구매자 | DHL 리포트 받는 사람 (없으면 Shopify 배송지 이름) |
| 목적국 | Shopify 배송지 국가코드 |
| 수량 | Shopify 주문 수량 |
| **단가** | Shopify 실제 결제 단가(할인 적용). 할인이 없는 품목은 정가. 가액 확인 창에서 고른 값·PC와 무관합니다. |
| 금액 / 총신고금액 | 단가 × 수량 / 주문 합계 + 배송비 |
| 모델명(규격) | Shopify 품목명 |
| 원산지 | 원산지 확인 창의 값 |
| 고정값 | 신고품명 `KEYBOARD PARTS`, HS CODE `8473.30-9000`, 인도조건 `DAP`, 화폐 `USD`, 환급 `Y`, 거래구분 `15`, 수출자 사업자번호 `1304377108`, 제조자 `미상` |
| SHIPPING FEE 줄 | DHL 리포트의 배송비가 있으면 추가 |

DHL 리포트에 없는 주문은 수출신고 파일에서 빠집니다. 송장번호와 무게를 알 수 없기 때문입니다. 포장대장에는 송장번호 없이 들어갑니다.

## 10. 자동화 중 주의사항

- **시작 전에 DEC 계정을 확인하세요.** 일반 주문은 일반 계정, 벤더 주문은 B2B 계정입니다. 자동화는 지금 로그인된 계정에서 그대로 진행돼서, 계정이 틀리면 주문이 다른 계정에 들어갑니다.
- 자동화가 진행되는 **DHL 탭은 건드리지 마세요.** 클릭하거나 다른 페이지로 이동하면 멈출 수 있습니다.
- DHL 탭을 닫으면 "DHL 탭이 닫혀 자동화를 중단했습니다"가 뜨고 작업이 정리됩니다. 다시 시작하면 됩니다.
- 한 번에 하나의 작업만 진행됩니다. 진행 중에 또 누르면 "이미 진행 중인 자동화 작업이 있습니다"가 뜹니다. 30분이 지났거나 DHL 탭이 닫힌 작업은 자동으로 정리됩니다.
- 가액 수정이 실패하면 **라벨을 출력하지 않고 멈춥니다.** 잘못된 가액으로 라벨이 나가지 않게 하기 위해서입니다.
- 주문이 많으면(DHL New 목록이 여러 페이지) 주문을 찾는 데 시간이 걸립니다.

## 13. 크롬 확장 프로그램 설치 / 업데이트

1. 저장소의 `dhl-automation-extension` 폴더를 PC에 받습니다. 업데이트할 때는 **폴더 전체를 교체**하세요.
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. 처음이면 **압축해제된 확장 프로그램을 로드합니다** → 폴더 선택. 업데이트면 확장 프로그램 카드의 **새로고침(↻)** 버튼
4. 카드에 **버전 1.3 이상**이 보이면 완료. int-shipping 페이지도 새로고침(Ctrl+Shift+R)하세요.

확장 프로그램 "오류" 화면에 쌓인 예전 기록은 **모두 삭제**로 지워도 됩니다.
